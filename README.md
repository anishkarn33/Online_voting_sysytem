# Online_voting_sysytem

A web-based Online Voting System developed to facilitate the election of college/class representatives in a secure and user-friendly manner.

## 🚀 Project Overview
The Online Voting System allows eligible users to cast votes digitally and view election results efficiently. The system is designed with a clean frontend interface and a backend powered by Django to handle voting logic and data management.

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Django)  
- **Database:** SQLite3 

## ✨ Features
- User-friendly voting interface  
- Secure vote submission  
- Real-time result display  
- Responsive design for different screen sizes
